# Website pages

## Edit website pages {#edit-pages}

**Goal:** Change the content of the Home, About, Services, Projects or Contact page.

1. Go to **Pages** in the CMS sidebar and navigate to the page you want.
2. Click **Edit**.
3. Build the page body using content blocks. Add a block with the **+** button, drag blocks to reorder, and use each block's menu to duplicate or delete it.
4. Preview your changes before committing them.
5. Click **Publish** to make the change live, or **Save draft** to keep working.

## Page structure {#page-structure}

The structure is fixed and cannot be rearranged:

```
Home
├── About
├── Services
│   └── Service pages (one per service)
├── Projects
└── Contact
```

Each service gets its own page created underneath **Services**. Those service pages are what customers can filter projects by.
