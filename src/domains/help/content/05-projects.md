# Projects

## Add or edit a project {#add-edit-project}

1. Go to **Projects**.
2. Click **Add Project**, or click an existing project to edit it.
3. Fill in the details:
    - **Title, address, city, region, postcode**: location and identity
    - **Description**: the body text shown on the project page
    - **Price and currency**: the contract value or sale price
    - **Specifications**: bedrooms, bathrooms, garage, floor area, lot size, land area (all optional)
    - **Status**: drives whether the project shows under the *Active* or *Past* quick filter
    - **Service**: which service this project belongs to, used for filtering and related projects
    - **Lead staff member**: the employee shown as the contact
    - **Project date**: controls ordering; newest appears first
4. Upload the **main photo** and up to six **gallery photos**.
5. Set **Published** to control visibility. Unpublished projects are hidden from the website entirely.
6. Save.

A published project appears immediately in the Projects list and, if recent enough, in **Featured Work** on the home page.

## Manage the Featured Work section {#featured-work}

1. Edit the **Home** page.
2. Open the **Featured Projects Section** panel.
3. Toggle **Show featured projects** on or off.
4. Change the **heading** if you want something other than "Featured Work".
5. Publish.

The three projects shown are chosen automatically: the three most recent published projects by project date. To change which ones appear, adjust project dates or publish status in **Projects**.
